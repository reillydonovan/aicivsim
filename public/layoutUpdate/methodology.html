Method · Methodology

What this site computes, and what it does not.

The composite score is a formula over four hardcoded number series per scenario. The number series were written by a person. No policy lever on this site changes any score, including the national policy actions in the strategy catalog. This page shows the code and the numbers.

Nothing on the rest of this site is believable without this page. If you read one thing here, read this one.

The entire computation

This is simScore(), fetched from js/shared.js as you loaded this page. It is the function that produces every 0–100 score on this site.

It interpolates four stored series, weights them, adds ten points if a boolean is true, and clamps. There is no state, no iteration, no feedback between systems, and no input from anything you can click.

The numbers underneath

A person chose these values. They were not fitted to observed data, produced by a simulation, or derived from published trajectories by a documented procedure. The shape of each curve is a judgement about how a world of that kind would go, written directly into an array.

Constitutive, not causal

This is the distinction the rest of the site is built on, stated for a reader who arrived here first.

A national policy action that maps to a model lever is part of what makes one scenario different from another. Carbon pricing is not a thing you do to the aggressive scenario; carbon pricing existing is part of what the word “aggressive” refers to. The action is constitutive of the world, not causal upon it.

The practical consequence: there is no quantity anywhere on this site that answers “how much would this action improve the score.” The question has no referent here. A score moves when the reader selects a different scenario, which is a different set of stored arrays, which is a different authored guess about a different world.

What this site does not do

Each of these is a thing a reader could reasonably assume from the interface.

  • It does not forecast. No output is a prediction, and no output carries a probability. The four scenarios are not weighted by likelihood, and nothing here claims one is more probable than another.
  • It does not fit anything to data. The live data layer fetches current real-world values and displays them beside the model's 2026 baseline. The comparison is presented to the reader. It does not adjust the model, and a divergence between them changes no projection.
  • It is not backtested. No historical period was run through it and scored. There is no accuracy figure for this site because there is no procedure under which one could be computed.
  • It has no uncertainty. Every projection is a single line. There are no confidence intervals, no ensemble, no seeds, and no sensitivity analysis. Perturbing an input is not possible, because there are no inputs.
  • The cross-system feedback weights do not feed back. The influence values shown between systems are authored figures rendered as a panel. No score is computed from another score.
  • The interactive levers on the system pages change the display. They redraw local illustrative figures on those pages. They do not propagate, and they do not reach the composite.

Then what is it for

It is a structured argument about how six systems interact. The claim is in the shape — which systems couple, what a trajectory of a given kind implies for the others, what would have to be true for a future to go one way. The digits carry none of it.

A reader who takes the number 28 from this site and uses it as an estimate has taken the one thing here that carries no information. A reader who disagrees with the shape of the business-as-usual emissions curve and can say why has used the site correctly.

What would have to change

For any number here to be more than illustrative, all of the following are required. None is built.

  • Values would have to carry their provenance. Every number tagged with where it came from, checked mechanically rather than by intention. The class system is specified — see epistemics — and three of its five classes carry content today.
  • Dynamics would have to be computed from sourced rules rather than stored as an array, with each rule citing a published source a third party could check.
  • Output would have to be an ensemble. One trajectory reads as prophecy. The spread across seeds and model families would have to be shown as prominently as any central line.
  • Divergence would have to be measured and published — including the uncomfortable result, where independent models agree and that agreement is evidence about shared training data rather than about the world.

There is a separate project specifying that engine. It is not part of this site, it produces nothing yet, and it carries explicit kill criteria — conditions under which the correct action is to stop rather than continue. Among them: if reasoning agents and heuristic agents produce indistinguishable outcomes, and if ensemble variance across seeds swamps the difference between scenarios. Either result would mean the approach cannot distinguish futures and must not claim to.

Until that exists, the numbers on this site are what this page says they are.
